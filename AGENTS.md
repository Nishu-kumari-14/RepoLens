# Project rules
- This project is specified in ARCHITECTURE.md. Read it before any task.
- Work on ONE phase at a time. Only the phase I name.
- Before coding, list the files you will create or change, then wait for my approval.
- Write tests for the phase's acceptance criteria and run them.
- Never execute downloaded repo code. Never hardcode or log API keys. Secrets only in .env.
- Zero-cost stack only. Do not add paid services, Redis, or TypeScript.
- Do not start the next phase.
